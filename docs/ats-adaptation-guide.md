# 国内校招 ATS 系统适配知识库

> 面向求职自动化的系统调研笔记：主流校园招聘官网背后使用的招聘系统（ATS）类型、登录方式、自动化可行性。
> 用途：投递前快速判断「这个网站能不能自动化 / 需要人工配合什么」。
> 内容均为系统能力层面的中性描述，不含任何具体公司业务信息。

## 系统速查表

| ATS 系统 | 常见域名特征 | 登录方式 | 表单数据共享 | 自动化可行性 |
| --- | --- | --- | --- | --- |
| 飞书招聘系 | `*.jobs.feishu.cn`（各公司独立子域名） | 手机号+短信验证码为主，部分支持邮箱 | ✅ 账号级全局共享（填一次到处复用） | ✅ 高（登录后可无人值守批量投递，见 feishu-auto-apply.md） |
| Moka | `app.mokahr.com` | 手机号 / 邮箱 / 微信；邮箱验证码前有**滑块拼图**（网易易盾，iframe 内） | ✅ 同一 Moka 账号跨公司复用 | ⚠️ 中（需人工过一次性滑块，之后登录态可持久化复用） |
| 北森 | `*.zhiye.com` | 仅微信扫码 | ❌ 独立 | ❌ 低（只能扫码） |
| hotjob / wecruit | `wecruit.hotjob.cn` | 仅微信扫码 | ❌ 独立 | ❌ 低（只能扫码） |
| 大疆自有 ATS | `apply.careers.dji.com` + 统一账号 `account.dji.com` | 微信 / 短信 / 密码；**注册仅手机号+短信** | — | ⚠️ 中（注册需短信配合，登录后常规投递） |
| 自研官网系统 | 各公司官网 | 多样 | — | 逐个探测 |

## 关键结论

1. **飞书系 = 性价比最高**：虽然每个 portal 需单独登录（短信验证码），但登录一次后表单数据全局复用 + 登录态可持久化，配合两阶段投递法（见 feishu-auto-apply.md）可实现真正的无人值守批量投递。
2. **Moka = 一次人工换长期自动**：滑块（网易易盾）在 iframe 内、headless 下无法程序化通过（canvas 读取为全黑）。但只需用户在真实浏览器**拖一次滑块**，验证码走邮箱后即可自动读码登录，登录态持久化后**跨公司复用**（一家 Moka 公司登录 = 全部 Moka 公司可用）。
3. **北森 / hotjob = 纯人工**：仅微信扫码，无任何自动化空间，直接跳转手动。
4. **邮箱验证码 vs 短信验证码**：邮箱验证码可用邮箱 API 自动读取（全自动）；短信验证码只能等用户报码。优先找邮箱验证码入口。

## 通用探测流程（新系统如何判断）

1. 打开目标校招官网 → 找到「登录/注册」入口并点击。
2. 观察登录弹窗：列出所有输入框（placeholder）与按钮文本，判断登录方式（手机/邮箱/微信/密码）。
3. 若有邮箱输入框 → 填测试邮箱 → 点「获取验证码」→ 观察是否触发滑块/图形验证（有则 headless 不可过）。
4. 若有 API 拦截能力（如 Playwright `page.on('response')`），检查职位列表页是否走 JSON API（可提取职位 ID）。
5. 结论分级：✅ 全自动 / ⚠️ 一次性人工后自动 / ❌ 纯人工。

## 各系统探测细节

### 飞书系

- 登录表单：`input[placeholder="手机号码"]` + `input#code[placeholder="验证码"]` + 隐私协议勾选 + 「获取验证码」按钮。
- 职位列表页路径通常为 `/{portal}/position/list`（各公司 portal 名不同，如 `/campusofXXX`）。
- 简历数据接口：`GET /api/v1/user/latest/resume`（账号级）。
- 职位数据接口：`/api/v1/search/job/posts`（需拦截页面自然请求）。
- 提交页路径：`resume/{postId}/apply`。

### Moka

- 邮箱登录：`input[placeholder="请输入邮箱"]`，可切换登录方式。
- 滑块：点「获取验证码」后弹出网易易盾拼图（iframe 内 canvas），headless 下 `getImageData` 全 0，无法分析缺口。
- 解法：真实浏览器拖一次 → 邮箱收码 → 自动填码 → 持久化登录态。

### 大疆系

- 登录跳转统一账号中心 `account.dji.com`（OAuth 模式，`client_id` + `redirect_uri` 回跳）。
- 登录页含「微信登录 / 短信登录 / 密码登录」三个 tab；注册页仅手机号+短信验证码。
- 投递限制：同一职位池每人限投 1 个且不可修改 → 选岗必须谨慎。

## 风控与反爬红线

- **短信验证码自动发送会被风控静默拦截**：headless 下点击「获取验证码」可能按钮无反应、手机收不到码。必须真实浏览器或用户手动触发。
- **部分官网 403 反爬**：纯 HTTP 客户端直接访问会返回 403，需真实浏览器 UA + 完整请求上下文。
- **同一账号批量投递**：控制节奏与数量（同公司 2-3 个匹配岗为上限），避免触发企业侧拉黑。
